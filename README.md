# Surgical Equipment Services (SurgicalEquip)

SurgicalEquip is a modern, high-performance React web application built for showcasing and exploring professional surgical instruments. It features a responsive, beautifully animated user interface designed to provide a premium experience.

## ✨ Features

- **Modern UI/UX**: Built with Tailwind CSS v4, featuring a sleek, spacious design with subtle glassmorphism and beautiful indigo/cyan gradients.
- **Smooth Animations**: Powered by `framer-motion` for fluid page transitions, hover effects, and scroll-driven animations.
- **Responsive Design**: Fully optimized for both desktop and mobile devices.
- **Dynamic Routing**: Single Page Application (SPA) experience using `react-router-dom`.
- **Fast Build Times**: Bootstrapped with Vite for instant server start and lightning-fast HMR.

## 🛠️ Technology Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS v4
- **Animations**: Framer Motion
- **Routing**: React Router DOM
- **Icons**: Lucide React & React Icons

## 🚀 Getting Started

### Prerequisites
Make sure you have [Node.js](https://nodejs.org/) installed on your machine.

### Installation

1. Clone the repository:
   ```bash
   git clone <your-repo-url>
   ```

2. Navigate into the project directory:
   ```bash
   cd surgical_Equipment_services
   ```

3. Install the dependencies:
   ```bash
   npm install
   ```

### Running Locally

To start the local development server:

```bash
npm run dev
```

Open your browser and navigate to `http://localhost:5173` to view the application.

### Building for Production

To create an optimized production build:

```bash
npm run build
```

You can preview the built application locally using:

```bash
npm run preview
```
